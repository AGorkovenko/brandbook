# brandbook

Генератор брендбуків: з брифу, логотипа й референсів компанії збирає готовий
PDF-брендбук, використовуючи AI для генерації візуалів (фотостиль, ілюстрації,
патерни, іконки, мокапи носіїв).

**Статус:** проєктування. Зафіксовано структуру брендбуку й архітектуру,
код пайплайну ще не написаний.

## Ідея

Користувач відмічає чекбоксами, які секції потрібні, кладе матеріали в `input/`,
запускає збірку — на виході PDF, у якому кожна сторінка містить не просто
картинку, а **вимірюване правило** застосування бренду.

## Ключові рішення

- **Вихід — PDF.** Проміжний формат HTML+CSS, друк через Playwright/Chromium.
  Той самий HTML пізніше стане веб-версією.
- **Логотип ніколи не генерується AI.** Тільки векторний асет клієнта,
  накладений поверх згенерованої сцени.
- **На криволінійних носіях логотип не накладається плоско.** Футболка, худі,
  чашка — displacement map + карта освітлення, зі стелею деформації, вище якої
  знак руйнується. Див. [`docs/04-mockups.md`](docs/04-mockups.md).
- **AI-провайдер — OpenRouter.** Один ключ на зображення й текст.
  Відео він не вміє — motion-секції подаються розкадровкою.
- **Якість моделі за роллю сторінки.** Мокапи носіїв і фотостиль ідуть на
  найсильнішу модель (18 із 26 візуальних секцій), дешева обслуговує лише
  підбір промпту й прев'ю і в PDF не потрапляє.
- **Текст на мокапах не генерується.** Модель отримує чистий носій без написів,
  типографіка накладається CSS поверх — інакше кирилиця перетворюється на
  псевдотекст, що видає AI.
- **Кожна секція має тип виробництва** (`text`, `diagram`, `computed`,
  `image-gen`, `composite`, `image-asset`) — саме це робить автоматизацію можливою.

## Налаштування

```bash
cp .env.example .env
# вписати OPENROUTER_API_KEY з https://openrouter.ai/keys
```

Матеріали клієнта кладуться в `input/`:

```
input/brief/       текстовий бриф про компанію
input/logo/        логотип у векторі (SVG/AI/EPS)
input/photos/      реальні фото продукту, команди, виробництва
input/references/  візуальні референси й приклади, що подобаються
input/fonts/       ліцензійні шрифти
```

Вміст `input/` та `output/` у `.gitignore` — матеріали клієнтів у репозиторій
не потрапляють.
